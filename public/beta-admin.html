Beta Admin Panel

Manage the beta version without affecting stable

🔄 Reload Beta Version

Reload beta files and notify beta users to refresh. This clears the server cache for beta modules and sends a notification to all users on the beta version.

Note: Stable version users will not be affected.

💻 CLI Command

You can also reload beta from the server console:

restart-beta

This command does the same thing as the button above.

🔑 Password Reset

Reset a user's password. The system will generate a temporary password that you can share with the user. They should change it after logging in.

👥 User Management

View all registered users and manage their accounts.

⚠️ Important Notes

  • Only admins can reload the beta version
  • Beta users will see a notification to refresh
  • Stable version is completely unaffected
  • No server restart required
  • Changes to beta files take effect immediately after reload
